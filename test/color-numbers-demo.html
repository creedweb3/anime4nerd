color tab: percent numbers you can type into, without a box (design preview, sample data)

All in percent. Every number can be clicked (or reached with Tab and Enter) to type a value; each version below shows that in a different way. Hover a row or a number to see it. While typing, the field is a line under the number, not a box. Sample values: hue −8°, brightness 110%, contrast 125%, saturation 140%, gamma 0.85, grain 2.0.
