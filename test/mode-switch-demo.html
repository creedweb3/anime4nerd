design preview: sample data, nothing here talks to the extension

Three ways to make "anime" and "manga" real per-site switches in the popup header. Every control toggles, in its own mock only. The modes are independent: on a page with both a video and manga pages, both can be on.

1two mode chips with state dots

filled dot = on for this site · hollow dot = off · dimmed, no dot = nothing of that kind on this page

chips changed: the status chip keeps only the preset letter (on/off moved to the mode chips); manga time reads "0.4 s/page".

Best at: smallest change, fits the existing bar. Cost: dots are subtle; nothing says what each mode does.

2joined mode switch

one control, two segments · each lights up on its own (✓ on, – off) · dimmed = nothing of that kind on this page

chips changed: the status chip keeps only the preset letter; manga time reads "0.4 s/page"; one caption line added under the bar.

Best at: one control, two modes, with a caption explaining them. Cost: lit segments can still look like tabs.

3mode row under the bar

each half: name, what it does, state in words, and a switch · the whole half is the button

chips changed: the "anime4k" name chip is gone; status, gpu/time, clock and bug-report chips are as today.

Best at: most explicit; name, purpose, state and switch together. Cost: about 70px taller, and repeats the card's switch.
